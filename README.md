# vignesh-portfolio

A premium, highly interactive personal developer portfolio website for **Vignesh** — Senior React.js Developer & UI-focused Frontend Engineer.

Built with **React, Vite, SCSS, GSAP, Framer Motion, and Lenis Smooth Scroll**.

---

## ⚡ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: SCSS & CSS Variables (Dark theme, glassmorphism, glowing micro-borders)
- **Smooth Scrolling**: Lenis (@studio-freight/lenis / lenis)
- **Advanced Animations**: GSAP, ScrollTrigger, Framer Motion
- **Icons**: Lucide React & React Icons
- **Interactive FX**: Canvas Confetti, 3D Parallax Tilt, Live Component Laboratory

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/vigneshmit/vignesh-portfolio.git
cd vignesh-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## ✏️ Customization

All personal details, skills, experiences, and featured projects are located in:
```
src/data/portfolioData.js
```
Simply edit this single configuration file to update your information.
